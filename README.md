# Space Gallery

Галерея для Android, которая понимает, что на ваших снимках, и не отправляет их никуда.
Поиск по смыслу, люди, текст на фото, места, уборка дубликатов — всё считается на самом
телефоне нейросетями, работающими локально.

## Что умеет

**Поиск по смыслу.** «Кот на диване», «закат у моря», «скриншот переписки» — CLIP сравнивает
запрос с содержимым снимков. Запросы понимаются и на русском. Рядом — «похожие фото» для
любого кадра и умные альбомы, которые собираются сами из того, что вы снимаете.

**Люди.** Лица находятся и группируются в людей; человека можно назвать, объединить группы,
добавить снимок вручную и убрать ошибку. Ползунок похожести настраивает, насколько охотно
группы сливаются.

**Текст и коды.** Распознавание текста прямо на снимке: можно скопировать, можно искать по
нему в галерее. Кириллица, английский и корейский. QR-коды и штрихкоды ищутся на любом
фото, даже если текста на нём нет.

**Места.** Геометки из EXIF превращаются в названия городов офлайн, по встроенной базе
GeoNames — без обращений к картам.

**Уборка.** Дубликаты, серии почти одинаковых кадров, размытые снимки, старые скриншоты и
большие видео — находятся и удаляются пачками.

**Деликатное.** Снимки, которые вы не хотите показывать случайному взгляду, определяются
на устройстве и скрываются из общей ленты.

## Приватность

Фотографии не покидают телефон. Приложению не нужен интернет для работы — сеть используется
ровно один раз, чтобы скачать файлы нейросетей, и больше ни для чего. Ни аналитики, ни
аккаунтов, ни облака.

## Установка

Скачайте APK из [релизов](../../releases) — тот, что соответствует процессору телефона:

| Файл | Кому |
|---|---|
| `app-arm64-v8a-release.apk` | почти всем современным телефонам |
| `app-armeabi-v7a-release.apk` | старым 32-битным устройствам |
| `app-universal-release.apk` | если не знаете, какой выбрать |

Нужен Android 9 или новее. При первом запуске приложение предложит скачать нейросети:
обязательные — около 266 МБ, плюс по желанию поиск на русском (135 МБ), точное распознавание
лиц (174 МБ) и корейский текст (13 МБ). По умолчанию загрузка идёт только по Wi-Fi.

Модели лежат на [Hugging Face](https://huggingface.co/sharapsoftware/space-gallery-models).
Пока они не скачаны, приложение работает как обычная галерея и ничего не анализирует.

## Как это устроено

Kotlin, Jetpack Compose, Room, WorkManager. Нейросети — ONNX Runtime Mobile:

| Задача | Модель |
|---|---|
| Поиск и похожие | CLIP ViT-B/32 (int8), многоязычный текстовый энкодер |
| Деликатное | лёгкий классификатор поверх CLIP + ViT NSFW на спорных кадрах |
| Лица | YuNet (поиск) + MobileFaceNet или ArcFace r50 (векторы) |
| Текст | PaddleOCR: детектор PP-OCRv3, распознаватели PP-OCRv5 |
| Коды | ZXing |

Индексация идёт фоном в двух темпах: на зарядке и в простое — в полную силу, в остальное
время тихо, с паузами, чтобы телефон не грелся. Скорость — около 140 мс на снимок на
Snapdragon 8s Gen 3 и около 380 мс на Snapdragon 680.

Подробности и замеры: [docs/performance.md](docs/performance.md).
Сборка релиза: [docs/release.md](docs/release.md). Модели: [models/README.md](models/README.md).

## Сборка

```bash
git clone <этот репозиторий>
cd SpaceGallery
./gradlew assembleDebug        # модели для отладки: ./models/install_models.sh
```

Отладочная сборка берёт модели из `app/src/debug/assets/models/`, релизная — скачивает их
с адреса, заданного в `gradle.properties` (`modelsBaseUrl`).
